1. About Molaglora

Molaglora is a booking and scheduling platform provided by ICE CODE for beauty centers and dental clinics. The app allows users to explore branches and book available appointments.

Molaglora does not provide medical services and acts only as a scheduling system between users and clinics.

2. Use of Service

Users must provide accurate information when using the application. Misuse of the system or creating false bookings is strictly prohibited.

3. Bookings and Cancellations

Users can book available time slots based on clinic schedules. Bookings cannot be modified after confirmation.

Cancellations are allowed at any time and must be handled directly with the clinic via phone or in-person communication.

4. Payments

Molaglora does not process payments. Users may upload payment proof for verification only.

All payments and refunds are handled directly between the user and the clinic. ICE CODE is not responsible for financial transactions.

5. Limitation of Liability

ICE CODE provides only the software infrastructure.

All medical services, treatments, and outcomes are the responsibility of the clinic and licensed professionals.

6. Account Security

Users are responsible for keeping their account credentials secure. Accounts may be reset or deleted upon request.
